# 发布验收记录

本次是 Windows 0.2.1 脱敏重打包与 Android 0.1.0 Preview 的私有仓库预发布，不是跨平台生产认证。

## 来源

- Windows 源码：原客户端当前 0.2.1 快照，仅在发布副本替换示例域名/账号标签与完善分发文档。
- Android 源码：原客户端 0.1.0 快照，保留已验证的运行逻辑，构建路径改为可配置。
- 用户反馈：Android 手机实际连接、使用正常。设备型号、系统版本、网络细节未记录；不推断其他机型已验证。

## 已知限制

- Android 此前的完整 Lint 仍有 68 项错误、240 项警告及 5 条提示，涉及资源读取、缺失翻译、特权广播权限和 API 37 隐藏接口。未关闭检查或隐藏该结果。
- Android 有 18 项 JVM 测试、5 项模拟器测试的已通过记录；模拟器验证了界面和 VPN 启动，原本的本地传输尝试超时。用户的真实手机联网成功补充了实机证据，不抹掉未通过的环境测试。
- Windows 需要管理员授权；当前安装包未数字签名，没有验证所有杀毒软件和 Windows 版本的安装行为。
- 两端没有正式自动更新系统。Android Debug 签名不能当成长期正式发布身份。
- 服务器模板提供兼容配置，不包含完整账户后台、自动到期调度或月流量计费，也未部署到实际服务器。
- 并非完整安全审计；脱敏检查、单元测试和端口可用不能证明所有网络条件及供应链安全。

本次发布检查的具体计数、附件哈希和模板校验结果另见 Release 说明及 `docs/PUBLISH-CHECKS.md`。
