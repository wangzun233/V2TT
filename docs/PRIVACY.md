# 隐私与发布边界

## 本次排除的内容

- 真实订阅 URL、Token、UUID、密码、账号列表及有效期记录。
- 线上服务器 IPv4/IPv6、节点域名、管理地址、SSH 端口和登录配置。
- SSH 私钥/公钥、Cloudflare API 凭证、证书私钥、签名密钥。
- Windows 个人配置、加密账号缓存、Android 应用数据与数据库。
- 原始截图、完整诊断报告、运行日志、设备标识、个人目录路径和历史发布包。
- 原工程 Git 历史及本地 Git 配置；发布仓库从全新脱敏快照开始，提交使用 GitHub noreply 邮箱。

保留 GitHub 项目账号名及应用 ID，用于项目归属和安装兼容；它们不是服务端地址或登录凭证。示例凭证均为明确不可用于生产的公开值。

## 安装包的隐私边界

Windows 发布副本的默认节点域名已替换为保留示例域名，并重新构建安装包，不能直接上传旧安装包。Android APK 不内置真实订阅。两端使用时需要用户自行导入自己的账号。

Windows 使用操作系统账号相关的加密保存订阅；Android 使用应用私有目录和设备保护，未额外加一层应用密码加密。服务器、DNS/CDN 服务商、目标网站和客户端日志仍可能看到各自所处理的网络元数据，不提供“匿名”保证。

## 防止以后误传

`.gitignore` 排除私钥、配置缓存、运行目录、日志和构建输出。新增文件先运行隐私检查，检查 staged diff，然后再提交。Git 忽略规则无法阻止已经跟踪的文件或人为强制添加，不能替代审核。

不要在 issue、Release 文案、Actions 日志、截图、文件名或压缩包内部附上订阅。私有仓库也不是密码保险箱。若发现泄漏，应立即撤销/轮换凭证；仅删除文件不能让历史泄漏失效。

本次没有读取、导出或修改实际服务器配置与账户库；服务器目录是依据客户端契约编写的占位模板。没有发布私人管理后台或月流量记录。

## 运行日志

诊断报告虽然有脱敏逻辑，分享前仍需检查是否包含域名、路径、账号名称和其他可识别信息。发生问题时先截取最小错误片段，不要上传整个数据目录。

GitHub 的私有仓库只能被授权成员访问；给其他使用者发送安装包时，只分享已审查的 Release 附件和使用说明，账号订阅另走私密渠道。
