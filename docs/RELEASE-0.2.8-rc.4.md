# Windows 0.2.8-rc.4 网络优化候选版

在 rc.3 安全、日志脱敏和轮询改进基础上实现网络优化。未修改 Android，未自动安装、切换当前连接或发布 GitHub。

- 新增 `.cn` 与本地域名解析规则；订阅 `network.secure_dns: "https"` 可选择 DoH，默认仍为 DoT。实际短测未证明 DoH 更快，不强制迁移。
- `network.dns_mode: "fakeip"` 可选；默认真实 DNS，游戏模式、直连模式和启用的游戏应用规则均抑制 FakeIP。退出或切换后可能需要等待应用 DNS 缓存过期。
- 日常节点增加可选 WS Early Data、HTTPUpgrade 和 Chrome uTLS；默认不启用，服务端需配套验证。
- TCP 节点增加互斥的 Vision / h2mux 选项。已有普通 TCP TLS 节点行为不变。
- 严格验证可选字段，HTTPUpgrade 私有路径同样脱敏，订阅参数变化可触发连接更新。
- 提供配对服务端片段和保守 sysctl 模板。TUIC 0-RTT 保持关闭。

方案中的固定延迟减少、吞吐增长比例、无条件 0-RTT 和“无需服务端配合”不能作为实测结论。本机握手和配置校验不等于生产 CDN 兼容、极限吞吐或长期稳定性测试。旧客户端不能假定兼容新入站；不要覆盖共用账号。

## 验证记录

- 23 项前端单元测试、41 项原生测试、13 项 Playwright 测试通过；线路文案变更后补跑 8 项 UI 测试通过。
- 原生测试包含 60 组新增配置组合校验，以及 WS、Early Data、HTTPUpgrade、Vision、mux 五组本机 TLS 数据传输（每组 3 次）。使用临时自签证书并明确加入测试信任，未关闭 TLS 验证。
- 现有 TCP 节点实测 DoH 与 DoT 各 3 次查询成功。单次冷查询分别约 4.1 秒和 2.5 秒，后续命中缓存；这不足以进行稳定性能比较，因此保留 DoT 默认。
- 线上只读检查确认 BBR、TFO 已开启，收发缓冲上限已为 16 MB。未修改生产入站、系统参数或订阅，未重启服务。
- 尚未完成新安装包的管理员安装、真实 TUN 长时运行、公司网络晚高峰或游戏实测；安装包未做代码签名。
