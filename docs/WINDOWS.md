# Windows 使用说明

## 安装

1. 从私有仓库 Releases 下载 Windows x64 的 **Setup** 安装包。
2. 运行安装程序，确认系统管理员授权。完成后通过桌面或开始菜单启动。
3. 输入自己的 V2TT 专属订阅，点击“验证并导入”。订阅链接等同账号凭证，不要公开。
4. 关闭其他正在运行的 TUN/VPN 客户端，选择“智能”并连接。

安装包已含 Electron、sing-box 和国内分流规则，不需要另装 Node.js、Python 或 WebView2。不能只复制解包目录中的主 EXE 到另一台电脑。

当前没有代码签名。遇到未知发布者提示时先核对仓库和 SHA256；不要关闭杀毒软件、TLS 校验或下载不明重打包版本。

## 日常操作

- 默认使用智能模式。需要 TUIC 时切换极速，OpenAI 相关流量仍使用 VLESS。
- 应用规则可为指定程序选择日常、游戏或直连出口。应用规则优先于一般国内分流；极速模式的 OpenAI 保护规则优先级更高。
- 关闭窗口会最小化到托盘；彻底退出请使用托盘菜单。
- 设置中可开启开机自启。它创建当前 Windows 账号的计划任务，登录后延迟启动到托盘；自动连接是独立开关。
- 直连模式会停止代理内核，不代表测速最快的代理模式。
- 流量为当前连接的内核统计，不是服务器按月账单。节点测试延迟不是游戏延迟。

## 升级和新电脑

先从托盘退出旧版本，再安装新版。升级前保留自己的订阅入口；账号缓存依赖当前 Windows 账号加密，不能通过复制缓存迁移到另一台电脑。

新电脑重新安装并导入自己的订阅即可。安装与卸载默认保留个人数据；需要删除凭证时，先在设置中移除订阅。

## 无法连接或白屏

检查是否同时运行其他 VPN、系统时间是否正确、订阅是否到期、当前模式是否可用。白屏时可从托盘尝试重新加载界面；重新加载界面不应重启代理。

诊断日志位于 `%APPDATA%\v2tt-client\runtime`。导出报告会做脱敏，但分享前仍需检查内容，不要上传完整账户缓存、订阅 JSON 或截图中的链接。

切换线路或修改网络设置可能短暂重连。请保留备用客户端，避免将测试版作为唯一联网方式。
