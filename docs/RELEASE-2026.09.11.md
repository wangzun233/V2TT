# V2TT 更新提醒预览版

Windows 0.2.3 / Android 0.1.2，内核 sing-box 1.14.0。

- PC 启动及运行期间每 6 小时检查更新，托盘右键可手动检查。
- Android 支持启动检查和新版弹窗，应用设置中可关闭自动检查。
- 点击更新打开本仓库发布页，不静默安装、不主动断开代理。
- 保留原有订阅及分流配置，未修改在线服务器。

## 安装

Windows 下载 `V2TT-Client-Setup-0.2.3-Windows-x64.exe`；Android ARM64 手机下载 `V2TT-Android-0.1.2-arm64-v8a-debug.apk`。

先退出旧客户端，再覆盖安装；手机选择更新，不要卸载或清除数据。更早版本没有更新提醒功能，必须先手动安装本版一次。未来推荐版本发布后，本版才能检测到更新。

## 校验及限制

附件 `SHA256SUMS.txt` 包含安装包和完整源码 ZIP 的校验值。源码 ZIP 包含两端代码、部署示例、构建脚本、许可证及固定内核源码。

Windows 12 项原生测试、10 项界面及弹窗测试通过；打包后另有 4 项测试通过。Android 22 项 JVM 测试、6 项模拟器测试通过。没有进行本轮 ARM64 真机测试或真实订阅测速。

此版本仍为预览版：Windows 未配置正式代码签名；Android 使用沿用的调试签名。核心由固定上游源码本地编译，不是官方预编译包。Android 构建工具警告及既有全量 lint 问题未在本次消除。

不包含私人订阅、服务器凭据或签名私钥。更新检查只请求公开索引，网络不可达时可以稍后重试。
