# Android 使用说明

支持 Android 8.0 及以上的 ARM64 手机。当前 APK 使用测试签名，不是应用商店正式发行包。

1. 下载 ARM64 APK，允许当前下载器/文件管理器安装它；安装后可收回“安装未知应用”权限。
2. 断开 Hiddify、Clash 等其他 VPN 应用。
3. 打开 V2TT Client，点击导入订阅或配置旁的加号，选择远程，粘贴自己的 V2TT 专属 HTTPS JSON 订阅。
4. 保存后选择智能模式并启动，确认 Android 的 VPN 授权。通知权限用于显示连接状态及停止入口。

智能模式为国内直连、国外 VLESS。极速模式为国内直连、国外 TUIC，但 OpenAI/ChatGPT 相关域名走 VLESS。全局使用 VLESS；直连保持本地 VPN 服务并直接访问目的地址。

首页“已启动”说明本地内核运行，不保证服务器可达。出现问题查看日志，并报告手机型号、Android 版本、Wi-Fi/移动网络、模式及脱敏错误。

用户已反馈自己手机可以连接并正常使用。开发环境另验证了 Android 15 模拟器安装、界面、VPN 授权和启动；这不等于所有厂商、系统版本和网络条件都已通过。

Android 配置位于应用私有目录，关闭系统备份。没有另加应用密码加密；不要把应用导出的订阅公开。卸载会删除本地数据，请提前保留自己的订阅入口。

尚无自动更新。正式签名如果与本版不同，可能无法覆盖安装；届时需按版本说明迁移，不能盲目卸载导致订阅丢失。
