# Windows 0.2.5-rc.4 网络恢复候选版

这是预发布，不是已经证实解决全部断网问题的稳定版本。Android 不变。

## 变更

- 后台检查内核控制接口、经虚拟网卡的 DNS 和系统 HTTPS；失败时补测显式代理出口，辅助区分故障位置。
- 连续三轮检测异常才尝试重新连接，每次手动连接最多进行两次健康恢复。单个检测网站故障会尝试另一目标，HTTP 403 不作为传输断网依据。
- 用户断开或切换连接后丢弃旧检测结果；流量计数接口可用不再掩盖网络异常。
- 完整保留内核 stderr 输出，每份内核日志上限约 8 MiB，另保留一份轮换文件。
- 增加虚拟网卡自身网段的回流防护，DNS 劫持规则优先。
- 极速模式 DNS 使用 TUIC，显式应用规则优先于默认 OpenAI 规则，Windows 进程匹配忽略大小写。
- 订阅名称、排序等无效配置变化不再触发重连；实际配置变化仍生效。
- 相比本地 rc.3，修复候选版本号的更新检查兼容性并提供安装版。

## 安装和回退

下载 `V2TT-Client-Setup-0.2.5-rc.4-Windows-x64.exe`。安装前从托盘完全退出旧 V2TT；不要同时开启另一代理软件的 TUN 或系统代理。安装会请求管理员权限，保留已有账号缓存和设置，无需重新导入有效订阅。

安装包没有数字签名，仅从本仓库下载并核对 SHA256SUMS.txt。不要为了运行而关闭杀毒软件。没有服务器账号的用户仍需自行获取兼容订阅；软件不内置私人节点。

如出现问题，退出此版本，使用之前确认可用的客户端；不要清除用户数据。日志保存在 `%APPDATA%\v2tt-client\runtime`，可能包含访问域名等信息，不要直接公开上传。

## 验证与限制

此前网络恢复改动通过 15 项配置测试、23 项原生测试和 6 项界面测试；安装版额外复测更新版本比较、构建和打包校验。真实内核生命周期及隔离 TUIC DNS 测试通过，rc.3 实际连接的首轮后台检查正常。

尚未完成长时间真实 TUN 连续运行验证，未证明此前间歇断网的唯一根因。重连会短暂中断应用连接；不提供无缝恢复或断网防泄漏保证。后台检测访问公共检测端点，并产生少量流量。不自动更换协议，不默认故障回退到直连。

本次不修改 stable.json，不向稳定通道用户强制推送候选版。
