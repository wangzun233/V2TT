# Windows 0.2.8 正式版

发布日期：2026-10-19。汇总 0.2.8 候选版的 Windows 改进；Android 保持现有 0.1.3 预览版，本次不发布 APK。

## 改进

- 独立 TCP 模式：国内直连，其他代理流量使用订阅的 VLESS TCP TLS 节点；缺少节点时明确提示，不静默回退为直连。
- 补齐 `.cn` 和本地域名解析规则。可选 DoH、FakeIP，默认仍为 DoT 与真实 DNS；游戏模式、直连模式或存在启用的游戏应用规则时停用 FakeIP。
- 日常节点可选 WS Early Data、HTTPUpgrade、Chrome uTLS；TCP 节点可选 Vision 或 h2mux，禁止同时启用。保留旧订阅默认行为，不自动改服务器、DNS 或在线线路。
- 线路页按实际配置显示协议；订阅的连接参数变化会触发更新，纯名称或元数据变化不打断连接。
- 健康探测在休眠或长时间停顿后丢弃旧失败次数，保留恢复次数上限和游戏模式保护。
- 窗口隐藏时状态轮询降为每 10 秒，恢复显示时及时刷新，避免重叠请求；内核健康监控不依赖窗口轮询。
- 加强结构化日志与导出报告脱敏，覆盖已知凭据字段、认证头、代理链接、编码链接和用户路径，包括历史日志导出。不是任意编码内容的保密保证。
- 增加 Windows CI、网络配置测试、真实本机 TLS 传输测试和脱敏服务端模板。

## 使用与兼容性

先退出旧版，再运行 `V2TT-Client-Setup-0.2.8-Windows-x64.exe` 覆盖安装。不要删除个人数据，安装包不内置账号或私人订阅。实际安装会暂时中断由该客户端提供的代理连接。

Early Data、HTTPUpgrade、Vision 和多路复用需要匹配的服务端配置及实际链路验证。不要直接修改旧 Windows/Android 客户端共用的入站。TUIC 0-RTT 保持关闭，不承诺固定提速百分比或公司网络 UDP 问题已解决。CDN 与直连的选择由管理员订阅决定，安装新版不会自动切换。

## 验证与限制

发布前已通过构建、lint、23 项前端单元测试、41 项原生测试和 13 项界面/Electron 测试（共 77 项）。原生测试包含 60 组新增配置组合的内核校验，以及 5 种传输的本机 TLS 数据传输。源码已通过已知隐私标记与实际私有凭据扫描；安装包完整性报告和 SHA256 随 Release 附件提供。

本机 TLS 测试不等于跨机器安装、生产 CDN 兼容、极限带宽或长期游戏测试。没有在本次发布流程中覆盖安装用户当前客户端或切换其活动 TUN。Windows 安装包未签名，系统或安全软件仍可能提示；需要自行核对发布来源与 SHA256。

私有订阅、服务器地址、运维备份、账号、测速原始记录和个人设置均不属于发布内容。
