# Windows 0.2.6 正式版

发布日期：2026-09-28。基于 0.2.6-rc.1 转正，保留已测试功能，不增加新协议或替换内核。Android 本次不发布新包。

## 主要改动

- 游戏模式：为 `Diablo IV.exe` 的 TCP/UDP 配置独立 TUIC 会话和 native UDP 转发；游戏规则在嗅探前匹配，并尊重显式应用出口设置。
- 游戏期间通用网络探测失败仅告警，不自动重启仍在运行的内核；实际进程崩溃恢复保留。
- 游戏模式限制大流量测速，仍允许延迟探测；游戏 TUN MTU 为 1400。
- OpenAI 连通性诊断按应用规则选择出口，明确未登录探测不代表 Codex 登录会话可用。
- 保留极速 DNS 随 TUIC 出口、国内分流、有限网络恢复、实时流量、托盘和开机自启功能。

## 下载与升级

下载 `V2TT-Client-Setup-0.2.6-Windows-x64.exe`，先退出旧版，再覆盖安装。无需清除订阅和个人设置。安装会要求管理员权限；安装包尚未进行代码签名。

安装包不包含账号、订阅或私人服务器配置。请自行导入 V2TT Client 专属 HTTPS JSON 订阅，不能用 Hiddify 订阅替代。

发布附件包含安装包、SHA256SUMS.txt 和 package-verification.json。对应源码为本 Release 的 Git 标签；内核及依赖许可证随包提供。

## 验证与限制

发布前 20 项配置测试、24 项原生测试、11 项桌面/界面测试通过，共 55 项。首轮并行界面测试有 4 项超时，打包完成后单工作进程重跑全部 11 项通过。安装包文件、内核/规则哈希、版本及 Electron 安全开关校验通过；源码及解包目录隐私扫描未发现私人标记。用户反馈候选版近期使用正常；这不代表所有网络环境都已验证，发布任务没有重新执行提权安装或长时间游戏测试。

游戏模式不保证降低到特定延迟、不提供物理带宽隔离，也不能强制游戏分配指定地区机房。目标站拒绝访问、运营商丢包、DNS 或服务器故障仍可能影响连接。服务端测速需要兼容测量服务。

Windows 更新索引在附件发布并核验后切换到 0.2.6；只提示更新和打开官方发布页，不静默安装。Android 的版本及更新入口维持不变。
