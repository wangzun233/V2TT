# 网络测速预览版

Windows 0.2.4 / Android 0.1.3（versionCode 4），内核保持 sing-box 1.14.0。

## 新功能

- 支持直连、VLESS、TUIC 三种测试线路，不改变正常上网的分流模式。
- 延迟测试显示五次 HTTPS 请求的中位数、延迟波动和请求失败次数。
- 下载、上传测试显示实时平均速度、约一秒采样的峰值和已确认传输量。
- 测速前确认流量消耗，可随时停止；每个方向最多 128 MiB 应用数据。
- 测试目标是自己的服务器，不是第三方测速站。
- 提供独立的服务器测速服务源码、systemd 单元与 Nginx 配置示例。

## 使用

覆盖安装前退出客户端，保留原订阅和个人数据。升级后重新连接一次。

- Windows：连接后进入「诊断 → 服务器测速」。
- Android：连接后在仪表盘打开「服务器测速」。
- 自建服务器须先部署对应服务，见仓库 `docs/NETWORK-MEASUREMENT.md`。

## 验证与限制

- Windows：6 项配置测试、14 项原生测试、11 项界面测试通过；打包后的 ASAR 启动和订阅测试通过，安装包完整性检查通过。
- Android：构建通过，API 35 x86_64 模拟器 7 项测试通过，320 × 640 小屏测速面板和流量确认弹窗已检查；本轮尚未验证真实手机网络。
- VLESS、TUIC 的实际服务器下载和上传测试已跑通。结果受网络、CDN、设备和并发流量影响，不是保证带宽或物理最大速率。
- 延迟是 HTTPS 往返，不是 ICMP；失败比例不是游戏 UDP 丢包率。TUIC 测速使用 HTTPS 经 TUIC 传输，不是原始游戏 UDP 基准。
- 协议开销及未完成上传会使实际计费流量与界面的已确认流量不同。
- 当前实现要求日常节点 HTTPS 和 TUIC 地址能到达同一测速源站；独立服务器架构需适配。
- Windows 尚无正式数字签名；Android 沿用调试签名，均按预览版提供。
- 更新提醒只引导到官方发布页，不静默安装。安装包不含订阅或个人账号。

附件包括 Windows 安装程序、Android ARM64 APK、对应源码和 SHA256SUMS.txt。
