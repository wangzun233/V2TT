# Windows 0.2.8-rc.1 本地候选版

本轮改善故障检测和恢复，不修改协议、DNS 分流策略或服务器订阅，不宣称解决所有 UDP 通路故障。未发布正式更新。

- 首次健康探测失败后，后续复查间隔由 30 秒缩短为 5 秒，仍需连续三次失败才触发恢复。
- 备用网页与显式代理探测并行执行，减少失败时的串行超时等待；HTTP 拒绝响应仍不当作断网。
- 自动重连仍最多两次；连续十分钟有正常健康样本后补回额度。中间失败、长时间缺失样本和系统时钟倒退都会中断健康累计。
- 重连额度耗尽时显示明确提示并记日志，不再无提示地跳过恢复。
- 游戏模式继续保留当前会话，不因普通探测失败自动重启。

不自动切换到直连或其他协议，不自动安装，不改变用户当前网络。遇到独立新建 TUIC 会话也失败的情况，需继续检查 UDP 通路；反复重启不是根治方案。

验证：20 项配置测试、28 项原生行为测试、12 项桌面/界面测试通过，共 60 项；安装包结构、版本、资源哈希和安全开关校验通过。未在本轮运行提权安装或完成长期稳定性测试。
