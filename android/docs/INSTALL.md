# 安装与使用

这是 V2TT Android 0.1.0 测试版，不是正式发行版。当前支持 Android 8.0 及以上的 ARM64 手机。

1. 将 ARM64 APK 传到手机后安装。系统询问时，允许当前文件管理器安装此 APK；安装完成可收回该权限。
2. 暂时断开 Hiddify、Clash 等其他 VPN 应用。同一时间通常只能运行一个系统 VPN。
3. 打开 V2TT Client，点击导入订阅图标或配置旁的加号，选择远程，粘贴自己的 V2TT Client 专属 HTTPS JSON 订阅并保存。Clash/Hiddify 的订阅格式不能直接使用。
4. 选择“智能”，点击启动，允许系统 VPN 授权。通知权限用于通知栏状态和停止操作。
5. 智能模式为国内直连、国外 VLESS；极速模式为国内直连、国外 TUIC，但 OpenAI/ChatGPT 域名走 VLESS。全局为全部 VLESS，直连为全部直连。

安装包不内置服务器账号，也不会自动创建账号或修改服务器。
订阅链接含登录凭证，不要发到公开聊天或截图中。

首页“已启动”代表本地内核启动，不代表服务器已经通过连接测试。
遇到问题先查看“日志”，反馈手机型号、Android 版本、所选模式和脱敏后的错误，不要发送完整订阅链接。

本版已验证模拟器安装、界面和 VPN 服务启动，尚未完成真实手机与实际节点的联网验收。
完整限制见 VALIDATION.md。暂时保留现有客户端作为备用，不要把本版作为唯一联网工具。
